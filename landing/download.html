ClearSkies
Web app Release notes

Free · No account · No API key

Get ClearSkies on every screen you explore from.

Desktop builds include the local terrain engine, which caches tiles, prepares WA DNR LiDAR and keeps saved areas available offline. The web app runs anywhere with WebGL2.

Terrain engine

From source

Run the engine on any computer with Node 22 or later. It serves the app on port 8765 and unlocks WA DNR LiDAR, raw USGS 1 m DEMs and offline downloads.

git clone https://github.com/RileyG44/clear-skies-portal && cd clear-skies-portal && npm install && node server.js

Linux, macOS or Windows · or open it in a GitHub Codespace
