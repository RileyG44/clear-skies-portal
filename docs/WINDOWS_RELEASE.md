Windows 10/11 x64. Download **ClearSkies-Setup-1.0.1-x64.exe** for one-click installation. It permanently installs Clear Skies and its terrain engine into your user profile, creates Desktop and Start shortcuts, and registers an uninstaller in Windows Settings. No Node.js or terminal setup needed.

**ClearSkies-Guided-Setup-1.0.1-x64.exe** provides a branded wizard, location selection, and a Tailscale information page. The ZIP is an optional portable alternative; extract the entire folder before launching.

- ClearSkies icon, full-bleed map, overlaid window controls, no standard title/menu bars.
- First-run setup guide compares browser-only use with the included terrain engine, explains private desktop/mobile access, and links to the official Tailscale site and its version-independent latest stable Windows installer.
- Tailscale is optional and installed separately. Automatic Tailscale engine setup and link generation are planned for the next update. Keep Clear Skies running and the engine computer awake to use its engine remotely.
- Engine availability and resolution depend on source coverage. Tailscale supplies connectivity, not higher-resolution imagery by itself.

These Windows packages are currently unsigned. Windows may show an unknown-publisher notice. SHA-256 checksums are included. Updates retain user data; uninstall does not delete saved app data.
