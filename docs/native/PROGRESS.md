## Findings while porting

- `cog.js:parseTiff` reports `complete: true` for a single-directory file
  whose strip/tile tables lie past the bytes it was given: the tables read as
  zeros, and `usgs.js` caches that header, so those blocks load as empty for
  the session. The Rust parser reports such a directory as incomplete. Not
  yet fixed in the JS engine.
- `cog.js:decodeTile` reads uncompressed and predictor-2 samples as
  little-endian regardless of the file's byte order, and skips predictor 2
  for samples wider than 8 bits. No current USGS product is affected.
